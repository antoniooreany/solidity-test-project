# Solidity Test Project

This is a test project designed for learning Solidity, Web3, and blockchain development.
It follows Spec-Driven Development (SDD) and strict Gitflow principles.

## Development Environment
- **Remix IDE**: For smart contract development, compiling, and testing.
- **Antigravity CLI**: For workflow automation.

## Gitflow Workflow
This project strictly follows Gitflow.
- `main`: Represents the production-ready state.
- `develop`: The main integration branch for ongoing development.
- `feature/*`: Used for developing new features.
- `fix/*`: Used for bug fixes.
- `release/*`: Used for release preparation.

## Getting Started
For local development with Remix IDE, use `remixd` to share the local directory:
```bash
npx @remix-project/remixd -s . --remix-ide https://remix.ethereum.org
```
